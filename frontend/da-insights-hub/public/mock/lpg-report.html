Explainability
SHAP
SHapley Additive exPlanations. 각 변수의 개별 예측 기여도를 정량적으로 분해.

Search Space: 선행연구 결과를 반영하여 LightGBM, XGBoost, CatBoost, RandomForest, Linear Regression 5개 모델을 탐색 대상으로 설정했습니다. FLAML이 각 모델의 하이퍼파라미터를 자동 최적화하며, 총 24회 시도(trial) 후 최적 모델을 선정했습니다.

Preprocessing Pipeline: 7단계 자동 전처리를 적용했습니다 — (1) DateTime 변환, (2) 이상치 IQR 클리핑, (3) 범주형 변수 라벨 인코딩, (4) 결측값 중앙값 대체, (5) 저분산(NZV) 컬럼 제거, (6) 층화 분할, (7) 스케일링. 전처리 파이프라인은 학습/추론 시 동일하게 적용됩니다.

Reproducibility: 모든 실험은 MLflow로 추적되며, 모델 바이너리, 전처리 파이프라인, 하이퍼파라미터가 아티팩트로 저장됩니다. 동일 데이터와 랜덤 시드(42)로 결과를 재현할 수 있습니다.

08 Key Insights
  1. CP + JKM + 유가 = 81.1%: 국제 에너지 가격 3개 변수가 LPG 판매 단가의 대부분을 설명합니다. 특히 사우디 아람코 CP가 단일 변수로 38.2%의 설명력을 보여 가장 지배적인 요인입니다.
  2. 환율 비선형 효과: 원/달러 환율이 1,450원 이상 구간에서 SHAP 기여도가 급격히 증가하는 임계효과가 관찰되었습니다. 환율 모니터링 경보를 1,450원 기준으로 설정할 것을 권장합니다.
  3. 계절성 13.2%: 난방 수요 지수(9.3%)와 계절 변수(3.9%)가 합산 13.2%의 기여도를 보이며, 동절기 가격 프리미엄이 통계적으로 유의합니다.
  4. CP-JKM 스프레드: CP 가격과 JKM 가격의 차이(스프레드)가 확대될 때 예측 불확실성이 증가하는 패턴이 발견되었습니다.
